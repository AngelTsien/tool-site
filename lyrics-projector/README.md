# 🎵 歌词投影 · 提词器（v1）

给教会敬拜用的歌词投影小工具：**一个控制窗口 + 一个投影窗口**，打开网页就能用，不用安装，不用联网。

## 怎么打开
- **推荐**：放到 GitHub Pages（把整个文件夹上传到仓库），用 `https://你的用户名.github.io/…/lyrics-projector/` 打开。
- 本机临时用：在文件夹里运行 `python3 -m http.server`，再打开 `http://localhost:8000`。
- 直接双击 `index.html` 也能投影，但**「照片识别歌词」不能用**（浏览器不允许本地文件运行识别程序）。
- 为电脑设计（1366–1920 宽屏，键盘鼠标操作），不适配手机。建议用 Chrome / Edge；Safari 也可以。

## 主日当天 3 步
1. 「📋 歌单」里选好今天的歌单 → 点 **▶ 开始投影**。
2. 点右上角 **🖥 打开投影窗口**，把弹出的窗口拖到投影仪/电视屏幕，**双击**（或按 F）全屏。
3. 回到笔记本上的控制窗口，按 **空格** 翻页。控制窗口能看到「当前」和「下一页」。

> 第一次打开投影窗口时，如果浏览器拦截弹窗，请在地址栏右侧点「允许弹出窗口」。

## 快捷键（翻页笔可直接用）
| 按键 | 作用 |
|---|---|
| 空格 / → / ↓ / PageDown / Enter | 下一页 |
| ← / ↑ / PageUp | 上一页 |
| Home / End | 第一页 / 最后一页 |
| **B** 或 **.** | 黑屏（再按一次恢复） |
| **L** | 标志页（教会 logo / 欢迎词），再按恢复 |
| Esc | 取消黑屏/标志页 |
| F（投影窗口里） | 全屏 / 退出全屏 |
| 提词器页：空格 | 开始/暂停滚动；↑↓ 调速；Home 回到开头 |

在投影窗口里按这些键也一样有效。点控制窗口里任何一张缩略图可以直接跳过去。

## 歌词怎么写
```
[主歌]
第一行
第二行

第三行（空一行 = 新的一页）
第四行

[副歌]
……
```
- 段落标签：`[主歌] [副歌] [桥段] [导歌] [尾声]`，也可以写 `[V1] [C] [B]`、`Verse 1`、`Chorus`、`V1:`、`C:`。
- **唱法顺序**：例如 `主歌 副歌 主歌 副歌x2 桥段 副歌` 或 `V1 C V2 C C`，副歌只要贴一次。留空就按歌词顺序。
- **中英对照**：中文一行下面紧跟一行英文，英文行会自动用小一号、不同颜色显示（可在「外观」关掉）。
- 设置里可以设「每页最多几行」，没空行的长歌词会自动分页。

## 📷 照片识别歌词
歌曲库 → 「📷 照片识别歌词」→ 拖入照片 / 简谱截图（也可以 ⌘V 粘贴）。
- **离线识别**（默认）：用 Tesseract（中文简体 + 英文），识别后自动去掉简谱数字、小节线、和弦、杂符号，并按每页 N 行分页。**一定要检查一遍**：简谱密集、照片歪斜或模糊时会有错字，标题行也可能被留下。
- **AI 识别**（可选）：在「设置」里填 OpenAI 兼容接口地址、模型和 API Key（只存在本机浏览器，导出备份时不会带上）。更准，能分主歌副歌，但要联网，会产生接口费用。

## 📋 歌单 & 🎼 歌曲库
- 歌曲可以打多个分类标签（赞美、敬拜、感恩、圣诞、复活节、儿童……也可以自己写），记录调号、速度、语言。
- 搜索框同时搜歌名和歌词。
- 每首歌显示「唱过几次 · 最近一次日期」（按歌单历史统计），排歌时避免重复。
- 歌单可以加：歌曲、经文/文字页（标题写出处，会显示在页底）、标志页。
- 「⧉ 复制所选」：把旧歌单复制成下个主日的新歌单再修改。

## ⬇ 导出
- **图片 ZIP**：每页一张 1920×1080 PNG，可发微信群或放进别的投影软件。
- **PPT**：.pptx，文字可以编辑，背景/字体/分页和投影一致（Keynote、PowerPoint 都能打开；渐变或图片背景会作为背景图）。
- **PDF**：整份歌单，每页一张。
- **歌单文字**（.txt）和 **歌单文件**（.json，可以发给同工导入）。
- 「设置/备份」里可以导出/导入全部数据。

## 🎨 外观
预设主题（经典黑底、深蓝渐变、白底黑字、暖色晨光、绿幕字幕），可调字体、字号、行距、颜色、对齐、上下位置、阴影、描边、背景（纯色/渐变/图片+变暗）、标志页图片和文字。字太多时会自动缩小。

## 📜 提词器
贴入讲稿/主持词（或从歌曲、歌单载入），调速度和字号，可镜像（反射式提词器），勾选「显示到投影窗口」就会在大屏上同步滚动。

## 数据保存在哪
全部保存在**这台电脑的这个浏览器**（IndexedDB），不上传任何地方。换电脑、换浏览器或清理浏览器数据前，请先「导出全部数据」。

## 文件说明
- `index.html` 控制台，`projector.html` 投影窗口
- `js/core.js` 歌词解析与渲染，`js/app.js` 界面，`js/ocr.js` 识别，`js/export.js` 导出，`js/seed.js` 示例数据
- `vendor/` 本地化的第三方库（Tesseract.js 5.1.1 + 中文简体/英文字库 4.0.0_best_int、JSZip、PptxGenJS 4.0.1、jsPDF），运行时不依赖任何 CDN
- 示例歌曲只用公有领域文本：《Amazing Grace》（John Newton, 1779）、诗篇 23 篇（和合本 1919 / KJV）。
